# Portafolio · Nicolas Ariza

Sitio personal hecho con Astro y Tailwind CSS. HTML estático, sin JavaScript de framework en el cliente (solo un script pequeño para el modo oscuro).

**Sitio:** https://ariza823.github.io/portfolio/

## Correr local

```bash
npm install
npm run dev
```

El contenido (experiencia, proyectos, habilidades) está en `src/data/content.ts`: para actualizar el portafolio solo se edita ese archivo.

Deploy automático a GitHub Pages con GitHub Actions en cada push a `main`.
